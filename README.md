# بورتفوليو يزيد العرايشه | YAZEED AL-ARAISHA

موقع البورتفوليو الشخصي الحديث والاحترافي (Ultra-Modern AI & Automation Portfolio).
يبرز البراعة الابتكارية للأستاذ **يزيد العرايشه (YAZEED AL-ARAISHA)** في تطوير حلول الذكاء الاصطناعي، الرؤية الحاسوبية (Gemini Vision OCR)، أتمتة مسارات العمل المتقدمة (n8n)، تحليل البيانات وذكاء الأعمال (Power BI)، وتطوير ونشر الأنظمة السحابية (Render & MongoDB Atlas).

---

## 🎨 الهوية البصرية ونظام الألوان المخصص

- **نظام الألوان الأساسي**:
  - `vulcanico`: `#FF4103` (التوهجات النيونية، أزرار الدعوة للإجراء، ومؤشرات التفاعل)
  - `noturno`: `#001621` (الخلفية الليلية العميقة وقواعد البطاقات الزجاجية)
  - ألوان مساندة: `#00e5ff` (السيان التقني الذكي) و `#002b40` (الأسطح المرتفعة)
- **أسلوب Glassmorphism فاخر**: بطاقات زجاجية عصرية بضبابية `backdrop-filter: blur(18px)` وظلال ناعمة وحواف متوهجة.
- **تأثيرات حركية فائقة التطور (GSAP & ScrollTrigger)**:
  - حركات ظهور متسلسلة وسلسة عند التمرير (Scroll & Reveal Animations).
  - عدادات رقمية متحركة للإحصائيات (Counter Animations) مع عزل اتجاه الأرقام.
  - تأثير الإمالة ثلاثي الأبعاد (3D Tilt Effect) للبطاقات مع انعكاس ضوئي متجاوب مع حركة الماوس.
  - أزرار مغناطيسية (Magnetic Buttons) ومؤشر ضوئي محيطي (Radial Spotlight).
- **خلفية كانفاس تفاعلية (Interactive Cyber Mesh)**: شبكة جزيئات عائمة تتصل بخطوط ضوئية متوهجة وتتفاعل حركياً مع حركة الفأرة والتمرير.
- **معرض تفاعلي للشاشات الحية (Interactive Showcase Modal)**: يتيح للزوار استعراض الشاشات الخمس الحقيقية لنظام Timesheet Analyzer بدقة كاملة وبتبويبات تفاعلية.
- **دعم كامل للغتين (Arabic RTL & English LTR)**: تبديل سلس فوري بدون إعادة تحميل الصفحة مع ضبط كامل لاتجاهات الأرقام والرموز.

## 🚀 الأنظمة والمشاريع المضمنة بروابط حية

1. **نظام تحليل كشوفات الدوام الذكي (Timesheet Analyzer)**:
   - الرابط المباشر المنشور على Render: [https://timesheet-analyzer.onrender.com/](https://timesheet-analyzer.onrender.com/)
   - محرك القراءة البصرية (Gemini Vision OCR) لتحليل كشوفات الحضور والانصراف تلقائياً.
   - خوارزمية ذكية لاحتساب الإضافي والخصومات (كل 8 ساعات = يوم).
   - إدارة الشفتات وقاعدة بيانات سحابية MongoDB وتصدير Excel و PDF.
2. **نظام إدارة الأصول وأوامر العمل والمخزون المحوسب (CMMS)**:
   - رابط مستودع GitHub: [https://github.com/yazeedalaraisha-star/CMMS.git](https://github.com/yazeedalaraisha-star/CMMS.git)
   - **لوحة تفاعلية حية مضمنة في البورتفوليو** مستخرجة من وثائق النظام (PDF):
     - تنبيهات نقص المخزون (Low Stock Alert) وتنبيهات الصيانة الوقائية (PM Alert).
     - مؤشرات الأداء الحيوية: 7 أجهزة، 5 جداول صيانة (التزام 80%)، 2 أوامر عمل نشطة، 7 قطع غيار، تكلفة إجمالية 91,700 JOD (وفر وقائي 32,095 JOD)، و MTTR بقيمة 11,172.0 ساعة.
     - 4 تبويبات تفاعلية: أوامر العمل (WOs)، الصيانة الوقائية (PM)، المخزون والقطع بالدينار الأردني (JOD)، والتقارير المالية وأداء الكادر الفني مع باركود الأجهزة MED-77102.
     - محرك بحث حي فوري (Live Search) لتصفية الجداول والمعدات لحظياً.
3. **تطبيق ميزانيتي الذكية للموبايل (Smart Budget AI)**:
   - تطبيق هجين ذكي لإدارة المصاريف والميزانيات الشخصية للموبايل بدعم التعرف الضوئي OCR، وتصنيف ذكي للنفقات، وتنبيهات تجاوز الميزانية.
4. **منظومة خطوط الأتمتة الذكية (AI Workflow Pipelines)**:
   - مسارات عمل مؤتمتة عبر منصة n8n معززة بوكلاء الذكاء الاصطناعي لمعالجة البيانات وتوليد التقارير.

## 🌐 خيارات النشر المجاني الفوري (Deployment)

### 1. النشر عبر GitHub Pages (الأسهل والأسرع):
1. أنشئ مستودعاً جديداً على حسابك في GitHub باسم `portfolio` أو `yazeedalaraisha.github.io`.
2. ارفع ملفات المجلد إليه (`index.html`, `css/`, `js/`, `assets/`).
3. توجه إلى إعدادات المستودع **Settings** -> **Pages** -> اختر فرع `main` وانقر **Save**.

### 2. النشر عبر Render:
1. في لوحة تحكم Render، اختر **New Static Site**.
2. اربط مستودع الـ GitHub أو ارفع الملفات، واترك `Publish Directory` فارغاً أو `./`.
3. اضغط **Create Static Site**.
